# World News in Brief — 22 November 2026

A single 1024×1024 PNG that sums up the world's news of **Sunday 22 November 2026**:
the Strait of Hormuz tanker escalation, the collapse of COP31 in Antalya, a Russian
warship struck in Benghazi, a magnitude-7.2 quake off Indonesia, and the US midterms.

`main.py` draws the image locally with Pillow (standard library only, no network) and
writes it to `/output/entry.png`. It is deterministic: two runs produce identical bytes.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
